# Value Stream Mapping & Process Optimisation for Technical Textiles

Where does a textile batch spend the most time waiting between weaving, coating and fabrication?

This independent portfolio project is at the planning stage. The proposed study uses synthetic technical-textiles manufacturing data. Implementation and evaluation are scheduled for a later build.

**Planned tools** — Python, SQL and value-stream mapping.

## First milestone

Trace a batch from release to finished-goods receipt, including a queue and a rework loop.
